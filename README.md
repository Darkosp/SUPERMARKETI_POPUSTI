# SUPERMARKETI_POPUSTI

Апликација за следење и споредување на попусти во македонските маркети.

## Што прави

- Секој ден во 10:05 ги презема ценовниците од маркетите (Vero, KAM, Tinex, ...)
- Филтрира само производи со попуст
- Класифицира производи по тип (инстант кафе, кисело млеко, ...)
- Прикажува дневна листа на попусти по маркет и по тип
- Корисниците избираат град, маркети и типови што ги интересираат

## Структура

- `scrapers/` — модули за преземање на цени по маркет
- `classifier/` — мапирање на производи во типови
- `api/` — FastAPI backend
- `web/` — Next.js frontend
- `scripts/` — помошни скрипти
- `data/` — примероци за тестирање
